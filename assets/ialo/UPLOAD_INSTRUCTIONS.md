# IALO · Assets para carrusel de aceptación V03

Subir los archivos exactamente en estas rutas para que el render con assets reales pueda encontrarlos.

## Fondos

Subir en:

```text
assets/ialo/backgrounds/acceptance/
```

Nombres exactos requeridos:

```text
Habitacion Luz 2.jpg
Habitacion Luz 3.jpg
Habitacion Luz.jpg
Silla Lluvia 2.webp
Silla Lluvia 3.jpg
Silla Lluvia.jpg
```

## Logo

Subir en:

```text
assets/ialo/logos/
```

Nombre exacto requerido:

```text
IALO_Logo_5b.png
```

Si el archivo original se llama `IALO_Logo_5b (1).png`, renombrarlo a `IALO_Logo_5b.png` antes de subirlo.

## Fuentes

Subir en:

```text
assets/ialo/fonts/
```

Nombres exactos sugeridos:

```text
Lyon Text-Regular.woff
LyonDisplay-Regular.woff
FuturaStd-CondensedExtraBd.woff
```

Nota: si el repo sigue siendo publico, revisar derechos de redistribucion antes de subir fuentes comerciales.

## Despues de subir

Cuando estos archivos esten cargados, se puede crear la version:

```text
templates/01_acceptance_inner_dialogue/v03-real-assets/
```

Y renderizar el carrusel usando las fotos reales.
